# MoBuVideoPlayer 0.2.1

MotionBuilder 2026 / Windows x64向けの動画・音声プラグインです。
Windows標準APIで読み込み、QuickTime等の追加再生ランタイムを使わず、標準Storyの動画・音声クリップとして編集できます。

- 標準Storyの再生、移動、トリム、速度変更、Muteに対応。
- 初回読込でPNG画像シーケンスとPCM WAVを作成し、以後は標準メディアとして使用。
- カメラ背景・前景・テクスチャへの直接動画読込にも対応。
- Install.ps1 / Uninstall.ps1でSDK検索パスを追加・解除。既存設定の保持、変更前バックアップ、WhatIfに対応。

## ダウンロードと導入

Assetsから `MoBuVideoPlayer-0.2.1-Mobu2026-win64.zip` と `.zip.sha256` を取得してください。
ZIPを保管して使う場所へ展開し、MotionBuilderを終了してから展開先で実行します。

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1
~~~

MotionBuilderを通常どおり起動し、**Open Reality > Tools > Native Video** から読み込みます。
解除するときはMotionBuilderを終了し、同じフォルダの `Uninstall.ps1` を実行します。
展開先のフォルダを利用中はその場所に保持してください。詳細はZIP内のREADMEを参照してください。

## 対象と制約

Windows x64 / MotionBuilder 2026専用です。macOS / Linux、DRM、ネットワーク入力、動画書出しは対象外です。
PNGはOSデコード後のBGRA8画素を保持します。VFRの固定FPSへのサンプリングやFloat32等の音声の24bit化には変換上の制約があります。
初回変換には待ち時間とディスク容量が必要です。

SDK、第三者の再生ランタイム、検証メディアは配布物に含みません。
プラグインDLLは手元のMotionBuilderで確認したものを配布します。CIはSDKなしのテストと入力DLLの照合・ZIP作成を行い、プラグインDLLを再ビルドしません。
試験環境と確認範囲はVALIDATION.md、依存関係とライセンスの状態はdocs/DEPENDENCIES.mdを参照してください。
